# Automation of weekly reporting process**


## Setting up new users

Couple steps to start using this
- Python / VSCode
- Packages
- .env file 
- file path (make sure forward slashes)
- week number
- email recipients


## how it works

- Using html template, and reading an excel tracker to fill in weekly/YTD values. 
- Using win32 to draft the report email locally in outlook.
